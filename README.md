# fibo | pasta bar

![Static Badge](https://img.shields.io/badge/status-refactoring-yellow) ![Static Badge](https://img.shields.io/badge/progress-95%25-green) ![Static Badge](https://img.shields.io/badge/pet_project-purple)

**fibo — интернет-магазин по заказу и доставке пиццы.** Удобный интерфейс позволяет авторизоваться, выбрать пиццу, добавить ее в корзину и оформить заказ.

## Установка и запуск
<a id="getting_started"></a>

- Клонировать проект

```
git clone https://github.com/GaynetdinovR/fibo.git
```

- Запустить

```
npm run dev
```

- Открыть в браузере

```
http://localhost:3000/
```

- **Интерактивная корзина товаров** — добавление/изменение количества/удаление товаров
